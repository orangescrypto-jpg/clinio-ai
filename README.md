Clinio AI
Advanced learning platform for nursing and medical students.
Features
Rapid Quiz Mode - Timed questions with instant answers and explanations
Clinical OSCE Mode - Step-by-step patient case simulations
Clinio Room - Educational content feed with discussions
Exam Mode - Full exam simulation (NCLEX, NMCN, medical exams)
Tech Stack
Frontend: React 18, TypeScript, Vite, Tailwind CSS
State Management: Zustand, TanStack React Query
Routing: React Router v6
Backend: Node.js, Express (coming soon)
